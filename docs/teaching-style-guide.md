# 零基础课程写作标准

这份标准用于后续修订所有课程。目标是让学习者只靠文档、脚本和输出，就能知道自己在学什么，而不是只会照着运行。

## 每一课必须回答的问题

每一课都要让学习者知道：

1. 这节课解决什么困惑。
2. 新出现的术语是什么意思。
3. 代码每一块在做什么。
4. 运行脚本时发生了什么。
5. 输出结果应该怎么读。
6. 学完后应该能用自己的话复述什么。

## 推荐结构

```text
本课目标
先把术语翻译成人话
核心概念解释
源码逐段讲解
运行脚本
输出怎么读
你真正学到了什么
可以自己改一改
检查问题
相关链接
```

## 写作原则

- 不把专业术语当成读者已经懂。
- 不只说“运行脚本，看到验证通过”。
- 每个 `torch`、`torchvision`、`nn`、`DataLoader` 等新工具第一次出现时，要解释它在本课里的作用。
- 源码讲解按执行顺序来，不按作者脑子里的抽象分类来。
- 输出必须解释含义，而不只是列期待文本。
- 练习要允许学习者改一个很小的地方，然后观察变化。

## 对代码的要求

- 教学脚本可以加注释，注释解释“为什么这样写”，不是重复代码本身。
- 脚本输出要能帮助学习者观察概念。
- 脚本最后的“验证通过”只代表自动检查通过，不代表学习者已经理解。
