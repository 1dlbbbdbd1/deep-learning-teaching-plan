# PyTorch MNIST 15 特征、标签、训练集和测试集

> 核心概念：feature、label、train set、test set

# 第 15 课：先把机器学习的“材料”分清楚

从第 15 课开始，我们暂时不急着写新模型。先把机器学习里最常见的几个词讲清楚：

```text
特征 -> 模型 -> 预测结果
标签 -> 用来判断预测对不对
训练集 -> 给模型学习
测试集 -> 检查模型有没有真的学会
```

如果这几个词混在一起，后面看线性回归、逻辑回归、CNN、ViT 都会很累。

## 特征是什么

特征就是模型拿来做判断的输入。

在 MNIST 里，一张图片是 28x28 的灰度图。对模型来说，它看到的不是“一个人写的 7”，而是一堆像素数字。

```text
图片像素 = 特征
```

之前的线性模型会先把图片展平成一行：

```text
[1, 28, 28] -> [784]
```

这 784 个数字就是这一张图片的特征。

## 标签是什么

标签就是标准答案。

比如一张图片对应的真实数字是 7：

```text
标签 = 7
```

训练时，模型会先猜一个结果。然后我们拿这个结果和标签比较，算出 loss。loss 越大，说明模型错得越离谱。

## 训练集和测试集为什么要分开

训练集用来给模型学习。测试集用来检查模型面对“没见过的数据”时表现怎么样。

如果模型只在训练集上表现好，测试集上表现差，它可能只是把训练数据背下来了。这种现象叫过拟合。

可以先用一个很朴素的理解：

```text
训练集成绩好 = 上课例题做得好
测试集成绩好 = 换一批题也能做对
```

机器学习更关心第二件事。

## 回到 MNIST 项目

前面课程里已经用过这些东西：

- `train=True`：训练集
- `train=False`：测试集
- `image`：特征
- `label`：标签
- `accuracy`：测试集上的准确率

第 12 课看到的 88.62% 准确率，就是模型在测试集上的表现。

## 本节常见误区

不要把“模型训练过的数据上的表现”当成真正能力。一个模型如果只记住训练集，而不能处理测试集，它在真实场景里通常不好用。

也不要把标签当成输入。训练时可以用标签算 loss，但预测一张新图片时，模型不应该提前知道答案。
