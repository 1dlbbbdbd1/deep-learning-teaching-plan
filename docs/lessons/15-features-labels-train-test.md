# PyTorch MNIST 15 特征、标签、训练集和测试集

> 核心概念：feature、label、train set、test set

# 第 15 课：先把机器学习的“材料”分清楚

从第 15 课开始，我们暂时不急着写新模型。先把机器学习里最常见的几个词讲清楚：

```text
特征 -> 模型 -> 预测结果
标签 -> 用来判断预测对不对
训练集 -> 给模型学习
测试集 -> 检查模型有没有真的学会
```

如果这几个词混在一起，后面看线性回归、逻辑回归、CNN、ViT 都会很累。

## 特征是什么

特征就是模型拿来做判断的输入。

在 MNIST 里，一张图片是 28x28 的灰度图。对模型来说，它看到的不是“一个人写的 7”，而是一堆像素数字。

```text
图片像素 = 特征
```

之前的线性模型会先把图片展平成一行：

```text
[1, 28, 28] -> [784]
```

这 784 个数字就是这一张图片的特征。

## 标签是什么

标签就是标准答案。

比如一张图片对应的真实数字是 7：

```text
标签 = 7
```

训练时，模型会先猜一个结果。然后我们拿这个结果和标签比较，算出 loss。loss 越大，说明模型错得越离谱。

## 训练集和测试集为什么要分开

训练集用来给模型学习。测试集用来检查模型面对“没见过的数据”时表现怎么样。

如果模型只在训练集上表现好，测试集上表现差，它可能只是把训练数据背下来了。这种现象叫过拟合。

可以先用一个很朴素的理解：

```text
训练集成绩好 = 上课例题做得好
测试集成绩好 = 换一批题也能做对
```

机器学习更关心第二件事。

## 回到 MNIST 项目

前面课程里已经用过这些东西：

- `train=True`：训练集
- `train=False`：测试集
- `image`：特征
- `label`：标签
- `accuracy`：测试集上的准确率

第 12 课看到的 88.62% 准确率，就是模型在测试集上的表现。

## 本节常见误区

不要把“模型训练过的数据上的表现”当成真正能力。一个模型如果只记住训练集，而不能处理测试集，它在真实场景里通常不好用。

也不要把标签当成输入。训练时可以用标签算 loss，但预测一张新图片时，模型不应该提前知道答案。

期待看到：


## 源码逐段讲解

### 1. 造一个很小的特征矩阵

```python
features = torch.tensor(
    [
        [0.0, 0.1],
        [0.2, 0.3],
        ...
    ]
)
```

这里一共有 6 行，每一行代表一个样本。

每个样本有 2 个数字，所以 `features.shape` 是：

```text
[6, 2]
```

你可以把它读成：

```text
6 条数据，每条数据有 2 个特征
```

### 2. 准备标签

```python
labels = torch.tensor([0, 0, 0, 1, 1, 1])
```

这里有 6 个标签，正好和 6 条特征一一对应。

第 1 条特征 `[0.0, 0.1]` 的答案是 `0`。

第 6 条特征 `[1.0, 1.1]` 的答案是 `1`。

### 3. 手动切出训练集

```python
train_features = features[:4]
train_labels = labels[:4]
```

`[:4]` 的意思是取前 4 条。

所以训练集里有 4 个样本，训练标签也必须有 4 个。特征和标签数量对不上，后面训练就会出错。

### 4. 手动切出测试集

```python
test_features = features[4:]
test_labels = labels[4:]
```

`[4:]` 的意思是从第 5 条开始取到最后。

所以测试集里有 2 个样本。

这不是标准项目里的随机拆分，只是为了让你看清楚“训练集”和“测试集”在代码里到底是什么。

### 5. 用检查保护自己

```python
if features.shape != (6, 2):
    raise RuntimeError("特征矩阵形状不符合预期。")
```

这类检查很重要。以后复刻项目时，很多 bug 都来自“我以为 shape 是 A，实际 shape 是 B”。

## 输出怎么读

- `特征矩阵形状：torch.Size([6, 2])`：6 条样本，每条样本 2 个特征。
- `标签形状：torch.Size([6])`：每条样本有 1 个答案。
- `训练集样本数：4`：前 4 条给模型学习。
- `测试集样本数：2`：后 2 条假装是没见过的新题。
- `第一条训练特征/标签`：确认特征和标签是一一配对的。

## 你真正学到了什么

机器学习不是一上来就“训练模型”。训练前必须先把材料分清楚：

```text
features 是输入
labels 是答案
train set 用来学习
test set 用来验收
```

如果这四个东西混了，后面的准确率就可能是假的。

## 你可以自己改一改

把：

```python
train_features = features[:4]
test_features = features[4:]
```

临时改成：

```python
train_features = features[:5]
test_features = features[5:]
```

再运行脚本。你会看到训练集样本数变成 5，测试集样本数变成 1。

这个实验想让你理解：训练/测试拆分本质上就是把数据切成两部分，只是实际项目里通常会更谨慎地随机拆分。
