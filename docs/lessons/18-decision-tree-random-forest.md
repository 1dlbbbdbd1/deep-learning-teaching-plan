# PyTorch MNIST 18 决策树和随机森林

> 核心概念：条件分裂、树模型、集成、过拟合

# 第 18 课：树模型和神经网络不是一类东西

决策树和随机森林是机器学习里的另一条路线。它们不像神经网络那样用梯度一步步更新很多权重，而是用一系列条件判断做预测。

你可以先把决策树想成一串问题：

```text
如果特征 A 大于某个值，走左边
否则走右边
继续问下一个问题
最后得到预测结果
```

## 决策树像什么

比如判断一个人今天要不要带伞：

```text
会下雨吗？
风大吗？
要出门多久？
```

决策树就是把这些判断组织成一棵树。每个节点问一个问题，每条分支代表一个答案。

## 它怎么学习

决策树训练时会寻找最有用的问题，把数据分成更容易判断的两部分。

直观理解：

```text
好的分裂：分完之后，每一边都更纯
差的分裂：分完之后，两边还是混乱
```

分类任务里，“更纯”可以理解成同一边的数据更像同一类。

## 随机森林是什么

一棵树容易过拟合。它可能把训练集里的细节记得太死。

随机森林的做法是训练很多棵树，然后让它们一起投票。

```text
树 1 觉得是 7
树 2 觉得是 7
树 3 觉得是 1
最终投票：7
```

很多棵树组合起来，通常比单独一棵树更稳。

## 和神经网络怎么区分

先记住这几个差别：

- 决策树靠条件分裂做判断。
- 随机森林靠多棵树投票。
- 神经网络靠线性层、激活函数、loss 和梯度更新参数。
- PyTorch 更常用于神经网络；树模型常见于 scikit-learn。

现阶段不需要马上掌握 scikit-learn。理解树模型是为了知道：机器学习不只有神经网络。

## 树模型适合什么

树模型经常适合表格数据，比如：

```text
年龄、收入、地区、消费次数 -> 是否购买
面积、楼层、位置、装修 -> 房价
```

图片、语音、文本这类高维数据，深度学习通常更常见。

## Debug 时先查什么

树模型常见问题不是梯度，而是数据本身：

- 训练集和测试集有没有混在一起？
- 标签是不是泄漏到了特征里？
- 类别特征有没有正确处理？
- 训练集表现很好、测试集表现很差，是不是过拟合？

后面做项目复刻时，不管模型多复杂，都要先问：数据有没有被正确拆分？

## 源码逐段讲解

### 1. 定义一条树规则

```python
@dataclass(frozen=True)
class ThresholdRule:
    feature_name: str
    feature_index: int
    threshold: float
    left_label: int
    right_label: int
```

这不是完整决策树库，只是一条“阈值规则”。

可以读成：

```text
看某个特征，如果它大于等于阈值，就预测右边类别，否则预测左边类别
```

### 2. 用规则做预测

```python
def predict(self, sample):
    if sample[self.feature_index] >= self.threshold:
        return self.right_label
    return self.left_label
```

比如 `feature_index=0` 表示看样本里的第 1 个特征。

`threshold=0.5` 表示用 `0.5` 当分界线。

### 3. 写一个投票函数

```python
def majority_vote(predictions):
    ones = sum(predictions)
    zeros = len(predictions) - ones
```

这里假设预测结果只有 `0` 和 `1`。

`sum(predictions)` 就能数出有几棵树投了 `1`。

### 4. 准备一个样本

```python
sample = [0.8, 0.6, 1.0]
```

这三个数字分别代表：

```text
亮度、圆润程度、笔画像素数
```

它们是人为起的名字，不是真实 MNIST 特征。目的是让你看懂树模型“按条件判断”的感觉。

### 5. 多棵树一起投票

```python
forest_votes = [tree.predict(sample) for tree in forest]
forest_prediction = majority_vote(forest_votes)
```

`forest_votes` 是每棵树自己的意见。

`forest_prediction` 是最终投票结果。

## 输出怎么读

- `样本特征`：当前要判断的输入。
- `单棵决策树规则`：只用一条条件做判断。
- `单棵决策树预测`：单棵树给出的结果。
- `投票明细：[1, 1, 0]`：三棵树里两棵投 1，一棵投 0。
- `随机森林投票结果：1`：少数服从多数。

## 你真正学到了什么

树模型和神经网络的思路很不一样：

```text
神经网络：用 loss 和梯度慢慢改参数
树模型：用条件判断把样本分到不同分支
随机森林：让很多棵树投票
```

这节不是让你掌握工业级随机森林，而是让你知道“不是所有机器学习模型都长得像神经网络”。

## 你可以自己改一改

把样本改成：

```python
sample = [0.2, 0.6, 1.0]
```

再运行脚本。你会看到第一棵树的预测可能变了，因为亮度低于 `0.5`。

如果脚本最后的检查失败，说明你改变了输入后，原来的预期输出也要一起改。这和真实项目里的测试维护是同一个道理。
