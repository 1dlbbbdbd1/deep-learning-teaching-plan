# PyTorch MNIST 16 线性回归

> 核心概念：连续值预测、直线、误差、拟合

# 第 16 课：线性回归在学什么

线性回归是机器学习里最基础的模型之一。它解决的问题不是“这张图是数字几”，而是预测一个连续数字。

比如：

```text
房子面积 -> 房价
学习时间 -> 考试分数
温度 -> 用电量
```

这些输出不是类别，而是一个可以变大变小的数。

## 一条线的模型

最简单的线性回归可以写成：

```text
y = w * x + b
```

这里不用怕公式，先把它当成一句话：

```text
输入 x 乘上一个权重 w，再加一个偏置 b，得到预测值 y
```

模型训练时真正要学的就是 `w` 和 `b`。

## 什么叫拟合

假设有几组数据：

```text
学习 1 小时 -> 60 分
学习 2 小时 -> 70 分
学习 3 小时 -> 80 分
```

线性回归会尝试找一条线，让这条线尽量贴近这些点。

这就叫拟合。

## 误差从哪里来

模型会先预测一个值，再和真实值比较：

```text
预测值 72
真实值 70
误差 2
```

线性回归常用平方误差。直观理解就是：错得越多，惩罚越大。

```text
误差 = 预测值 - 真实值
损失 = 误差的平方
```

## 它和前面 MNIST 模型有什么关系

第 05 课到第 14 课里，我们已经用过线性层：

```python
torch.nn.Linear(28 * 28, 10)
```

这个线性层本质上也是在学权重和偏置。区别是：

- 线性回归通常预测一个连续值。
- MNIST 线性分类模型输出 10 个类别分数。

所以线性回归不是孤立知识。它是理解神经网络线性层的地基。

## Debug 时先查什么

线性模型最容易出错的是输入形状。

如果模型期待：

```text
[batch_size, feature_count]
```

你却传入：

```text
[batch_size, 1, 28, 28]
```

就会报 shape 相关错误。后面复刻项目时，一看到 shape 报错，第一反应应该是打印输入和输出的形状。

```powershell

```

期待看到：


这是一个很小的训练脚本。它不使用 MNIST，只让模型学习 `y = 2 * x + 1`，目的是看见 loss 下降、参数靠近目标值。

## 源码逐段讲解

### 1. 固定随机种子

```python
torch.manual_seed(RANDOM_SEED)
```

模型一开始的 `w` 和 `b` 是随机值。固定随机种子后，每次运行更容易看到相同结果，方便学习和 Debug。

### 2. 准备训练数据

```python
x_train = torch.tensor([[-2.0], [-1.0], [0.0], [1.0], [2.0]])
y_train = 2 * x_train + 1
```

`x_train` 是输入特征，只有 1 个特征。

`y_train` 是正确答案。这里答案不是人工写死的，而是用目标公式算出来：

```text
y = 2 * x + 1
```

所以模型的目标就是学到接近 `w=2`、`b=1`。

### 3. 创建最小线性模型

```python
model = nn.Linear(1, 1)
```

第一个 `1` 表示每条样本只有 1 个输入特征。

第二个 `1` 表示每条样本输出 1 个连续数字。

### 4. 选择损失函数

```python
loss_function = nn.MSELoss()
```

`MSELoss` 是均方误差。先按人话理解：

```text
预测值和真实值差多少，差得越大，惩罚越大
```

分类任务用过 `CrossEntropyLoss`，这里是回归任务，所以换成 `MSELoss`。

### 5. 重复训练 300 步

```python
for _ in range(TRAINING_STEPS):
    predictions = model(x_train)
    loss = loss_function(predictions, y_train)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

这段和前面的 MNIST 训练骨架一样：

```text
预测 -> 算 loss -> 清梯度 -> 反向传播 -> 更新参数
```

区别只是数据更小、模型更简单、loss 换成了回归用的 MSE。

## 输出怎么读

- `训练目标：y = 2 * x + 1`：标准答案来自这条直线。
- `初始 loss`：模型还没学习前错多少。
- `最终 loss`：训练后错多少，应该明显更低。
- `学到的权重 w`：应该接近 2。
- `学到的偏置 b`：应该接近 1。

不要只看“验证通过”。真正要看的是：loss 下降了，并且参数靠近目标公式。

## 你真正学到了什么

线性回归训练出来的不是魔法，而是两个数字：

```text
w 控制斜率
b 控制整体上移或下移
```

神经网络里的 `Linear` 层也是在学权重和偏置。线性回归只是把这件事缩小到最容易看懂的版本。

## 你可以自己改一改

把：

```python
y_train = 2 * x_train + 1
```

临时改成：

```python
y_train = 3 * x_train - 2
```

再运行脚本。注意：脚本后面的检查还在要求 `w` 接近 2、`b` 接近 1，所以它会失败。

这个失败是好事：它说明测试不是摆设。你如果改变了学习目标，也必须同步改变验证条件。
