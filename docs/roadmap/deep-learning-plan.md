# PyTorch 深度学习快速入门与项目复刻 Debug 计划

> 状态：公开学习路线
>
> 节奏：每天约 1 小时，预计 10 周
>
> 路线：以 MNIST 闭环为基础，先补齐机器学习和深度学习核心，再复刻 CNN，最后拆解 ViT。

## 一、当前基线

MNIST 最小识别项目已经完成：环境、PyTorch、数据读取、DataLoader、线性模型、损失、梯度、优化器、训练循环、评估、保存、加载和单张预测。

这份计划不重复执行 MNIST 基础课，而是安排 MNIST 之后的系统提升和项目复刻训练。基础课程见 [`../course-index.md`](../course-index.md)。

这条路线已经拆成完整课表：主线编号 00–36，加上 01.5 过渡课，共 38 篇课程笔记。详见 [`full-course-outline.md`](full-course-outline.md)。

## 二、十周学习路线

### 阶段 0：基础补齐与 MNIST 复盘｜第 1 周

- 函数、类、模块、文件路径和异常信息。
- 列表、字典、循环、条件判断和简单调试输出。
- 向量、矩阵、函数、导数、梯度和概率的直观含义。
- 复盘数据 → batch → 模型 → loss → 梯度 → 参数 → 评估。

验收：能用自己的话解释一个 batch 如何经过训练循环，并能读懂项目中的主要 Python 结构。

### 阶段 1：机器学习基础算法｜第 2 周

依次理解线性回归、逻辑回归、决策树和随机森林。每个算法都沿用同一条主线：

```text
输入数据 → 模型预测 → 计算误差或指标 → 拟合/更新 → 评估结果
```

验收：能区分特征、标签、训练集、测试集、预测值和指标，并说明线性模型与树模型的基本差异。

### 阶段 2：PyTorch 深度学习基础｜第 3–6 周

- 第 3 周：Tensor、shape、dtype、device、Dataset、DataLoader 和预处理。
- 第 4 周：`nn.Module`、线性层、logits、交叉熵、前向传播、反向传播和优化器。
- 第 5 周：隐藏层、激活函数、学习率、batch size、epoch、训练/评估模式和过拟合。
- 第 6 周：卷积、特征图、池化，以及一个最小 MNIST CNN。

验收：能从头运行训练、测试、保存、加载和预测闭环。

### 阶段 3：项目复刻与 Debug｜第 7–10 周

#### 第 7 周：复刻一个最小 CNN 项目

先运行原项目，确认入口、依赖、数据和配置；再只阅读入口、数据加载和模型定义，画出数据流，逐个补齐模块。

#### 第 8 周：系统练习常见故障

故意制造并修复解释器错误、路径错误、shape 错误、dtype 错误、device 不一致、梯度错误、学习率错误和保存/加载不一致。

#### 第 9 周：复刻 ViT 的最小版本

按图片切 patch、映射 embedding、位置编码、Transformer Encoder、分类头、训练评估的顺序拆解，每一步先检查 shape、数值、参数和梯度。

#### 第 10 周：综合故障复盘

准备一个包含 5–8 个故意错误的 CNN 或 ViT 项目，完整记录现象、最小复现、假设、检查证据、根因、最小修复和回归验证。

## 三、Debug 工作流

固定执行：

```text
复现问题 → 缩小输入 → 提出可验证的假设 → 增加证据 → 最小修复 → 回归验证
```

详细步骤见 [`../debugging/debug-workflow.md`](../debugging/debug-workflow.md)。

## 四、每日学习节奏

- 10 分钟：复习昨天的代码和笔记。
- 20 分钟：学习一个新概念。
- 20 分钟：亲自修改、补全或验证代码。
- 10 分钟：记录观察结果、疑问和 Debug 证据。

每周安排 4 天学习新知识、1 天故意制造并修复故障、1 天复盘整理、1 天休息或补漏。

## 五、最终验收标准

- 读懂完整报错并提取有用信息。
- 用打印、断点和最小输入定位问题。
- 检查 shape、dtype、device、数值范围和梯度。
- 区分数据错误、模型错误和训练配置错误。
