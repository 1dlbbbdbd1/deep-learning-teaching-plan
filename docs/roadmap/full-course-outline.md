# PyTorch 深度学习完整课程大纲

> 终点：能复刻一个最小 CNN/ViT 项目，并能按固定流程 Debug。

这套课按最初商量的路线补齐到第 36 课。编号从 00 到 36，另外有一节 01.5 过渡课，所以一共是 38 篇课程笔记。

## 课程数量

- 主线编号课：00–36，共 37 课。
- 过渡补充课：01.5，共 1 课。
- 合计：38 篇课程笔记。

## 阶段划分

| 阶段 | 课程 | 目标 |
| --- | --- | --- |
| 环境与 PyTorch 入门 | 00–04，加 01.5 | 知道代码由哪个 Python 执行，认识 PyTorch、MNIST、Tensor、DataLoader |
| 最小 MNIST 闭环 | 05–14 | 跑通模型、loss、梯度、优化器、训练、评估、保存、加载、预测 |
| 机器学习基础 | 15–18 | 分清特征、标签、训练集、测试集，理解线性回归、逻辑回归、树模型 |
| 深度学习基础 | 19–25 | 理解 shape、dtype、device、Dataset、nn.Module、激活函数、MLP、过拟合 |
| CNN | 26–28 | 理解卷积、池化、通道和最小 CNN 训练闭环 |
| 项目复刻 | 29–31 | 学会先跑通原项目，再拆数据、模型、loss 和训练入口 |
| Debug 专项 | 32–33 | 用复现、缩小、假设、证据、修复、回归验证处理常见错误 |
| ViT 与收官 | 34–36 | 拆解 patch embedding、Transformer Encoder、分类头，并写复刻复盘报告 |

## 学习方式

不要一口气学完。每次只做一件事：

1. 读本课目标。
2. 看懂一个关键概念。
3. 跑一个已有脚本，或完成本课实操清单。
4. 记录现象、疑问和 Debug 证据。

除第 01.5 课是过渡阅读课外，每一课都配有一个可运行脚本。第 19–36 课的脚本以轻量演示为主，避免下载新数据或长时间训练，让学习者能靠文档和脚本独立走完整条路线。
